# 观页 · PPT 评分工作台

团队网页版使用 GitHub Pages + Supabase，支持每人独立评分、各人明细与团队均分。部署说明见 cloud/README.md。本机版与云端版共用界面，通过 cloud-config.js 切换。

双击 **启动评分系统.cmd**，浏览器会打开 http://127.0.0.1:8765 。需要 Python 3.10 及以上。无需安装前端工具、注册账户或联网。

## 已接入的图片库

默认读取 C:/Users/LENOVO/Desktop/小红书PPT模板/手动收集/裁切汇总，每个子文件夹视为一套 PPT，共 57 套、485 张图片（初次扫描）。图片只读；新增图片保存到项目自己的 data/imports 文件夹。

原文件夹新增或改动图片后，在网页中点击“刷新图片库”。图片按文件名自然排序；当前源文件部分名称是哈希，系统不猜测 PPT 页序。

## 使用

- 点击作品封面进入评审。可逐张浏览、查看整套总览，或点击图片打开原图大图，继续点击可放大查看竖长拼图。
- 每套 PPT 默认评“视觉效果”和“排版”两项，满分 5 分。点击分数按钮，或直接输入数字（支持 0 分与小数）。综合均分按当前已填写评分项等权计算；全部填写后才算已完成。
- “评分设置”支持添加、重命名、移除评分项，最多 12 项；满分可设置为 1–100。改变满分会按比例换算已有分数。移除的项保留历史分数，但不计入当前均分；重新新建同名项会得到一个新评分项。
- 作品支持收藏和笔记，可按关键词、色系、评分状态筛选，按均分或最近评分排序。
- “导入作品”支持多张图片、文件夹、上级文件夹批量导入。一套中的图片也可在评审页用“添加图片”追加。单张最多 25 MB、每批最多 100 MB / 600 张。上级文件夹以第一层子文件夹分组，单独选一套文件夹时按一套导入。
- “选择 PPT / PDF”支持 .ppt、.pptx、.pdf，多选时每份文档单独成套；单份可自定义作品名。也可将文件拖入导入区，或在已有作品中追加文档页面。文档与图片请分批导入。每批最多 10 份文档、合计 100 MB，每份最多 600 页。
- 文档导入在后台转换，窗口显示转换进度；成功后按原始页序生成预览。PDF 使用 PyMuPDF，PPT / PPTX 优先使用本机 PowerPoint，也支持 LibreOffice 回退。加密文档需先移除密码。转换失败时不会提交本批作品，可修复文件后重试。
- 评分自动保存到本地 SQLite 数据库。请看到“已保存到本地”后再关闭页面。如未保存，点击状态文字重试。
- “导出与备份”可下载 Excel 可读的 CSV 和可恢复的 JSON 评分备份。JSON 不含图片；迁移整套系统时需保留源图片和整个 data 文件夹。恢复备份会覆盖当前评分设置与记录，并先自动下载一份当前备份。
- 键盘：作品库按 / 搜索；评审页按 ← / → 切图；Esc 关闭大图、弹窗或返回作品库。

## 文件与启动

- server.py：Python 本地服务，监听 127.0.0.1，仅本机访问。
- public/：纯 HTML / CSS / JavaScript 界面，无构建步骤。
- data/library.sqlite3：评分、评分设置、收藏、备注与导入索引，请保留。
- data/imports/：导入图片；data/thumbs/：可重新生成的缩略图。
- data/documents/：导入的 PPT / PDF 原文件；data/work/：转换期间的临时文件，任务结束自动清理。文档导入需安装 PyMuPDF（python -m pip install PyMuPDF）；PowerPoint 接入需 pywin32。本机所需工具已就绪。
- data/server.log、data/server-error.log：启动日志。

直接运行：

    python server.py

使用其他源目录或端口：

    python server.py --source "D:/PPT图片库" --port 8766

Pillow 为可选依赖：安装后可生成缩略图并验证导入图片。本机已有 Pillow；未安装时可运行 python -m pip install Pillow。

关闭浏览器后服务会继续留在后台，再次双击启动即可使用。需要停止服务时，可用任务管理器结束此项目的 Python 进程。不要同时在多个窗口改评分；系统会检测版本冲突并提示导出与刷新，避免覆盖另一窗口的更改。
